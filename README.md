## Descripción
Bajo propuesta de la materia de Taller de Lenguajes de Programacion I, se nos propone el desarrollo de un sitio web
de caracter consistente y responsivo; escalable. Bajo decision del grupo conformado por sus integrantes, se eligio 
trabajar a partir de la tematica del Centro Cultural; y en su defecto del Sotano Cultural, respondiendo a contenido 
Informativo y aplicacion del contenido funcional del framework Bootstrap.

  <br> </br>
  <br> </br>
  
## Componentes de Bootstrap utilizados

- Formato Responsive (Overflow)
- Organizacion del contenido (Class = Conteiner, Container-fluid)
- Organizacion del contenido (row y col-md-*)
- Limpieza de listas (List-unstyled)
- Sistema de grillas (Grid) con container, row y col responsivos
- Utilidades de bordes y sombras (border, rounded-circle, shadow, overflow-hidden)
- Relación de aspecto para video (ratio ratio-16x9)
- Utilidades de orden (order-1, order-md-2)
- Utilidades de tamaño (w-100, w-sm-auto)
- Utilidades de tipografía (fs-*, fw-bold, fw-semibold, text-secondary)
- Utilidades de espaciado (p-*, m-*, py-*, mb-*, g-*)
- Utilidades responsivas de visibilidad (d-none, d-lg-flex, d-lg-none)
- Utilidades de Flexbox (d-flex, flex-column, flex-sm-row, align-items-center, gap-*)
- Menú colapsable para móvil (collapse con data-bs-toggle)
- Alerta de éxito (alert alert-success)
- Botones estilizados (btn-danger, btn-warning, btn-outline-secondary)
- Grupo de inputs con prefijo (input-group, input-group-text)
- Inputs estilizados (form-control, form-label, form-check)
- Formulario con validación nativa (needs-validation / was-validated)
- Modal con formulario de registro
- Carrusel automático de imágenes (carousel slide)
